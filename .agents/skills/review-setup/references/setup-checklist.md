# Список проверок настройки

- [ ] Windows подтверждён; источник RDV AIR определён как ZIP-архив релиза или Git checkout.
- [ ] Git и Python 3.11+ доступны; версии проверены.
- [ ] Исполняемый файл `review-tasks` доступен по PATH; `review-tasks --help` работает в окружении будущего запуска. Один лишь `python -m review_tasks` готовностью не считается.
- [ ] Опциональное сравнение кода предложено: при выборе KDiff3 или другого поддерживаемого инструмента проверено наличие приложения и при необходимости настроен `[diff_viewer]`; иначе отмечен пропуск без блокировки настройки.
- [ ] Репозиторий проверяемого проекта получен из указанного локального пути или клонирован в согласованный каталог.
- [ ] Корень Git-репозитория и URL выбранного remote проверены.
- [ ] Неинтерактивный доступ к remote проверен с отключёнными запросами учётных данных и ограничением времени ожидания; `git fetch <remote> --prune` успешен.
- [ ] Выбранный исходный ref существует после fetch.
- [ ] `reviewsRoot` находится вне репозитория проекта и доступен для записи.
- [ ] Выбран один AI-агент. Для ручного запуска готова авторизованная IDE-сессия; для Jira выполнены описанные version/help/auth проверки выбранного headless CLI. Если выбран OpenCode, установлен только `opencode-ai@1`, `opencode --version` сообщает major `1`, а `@opencode/cli`/V2 отсутствует.
- [ ] Только для OpenCode V1 с RouterAI: выбран один файл глобальной конфигурации, сохранён формат V1 (`provider`/`npm`/`options`), RouterAI добавлен объединением настроек, `opencode models routerai` видит провайдера/модель без запроса к LLM; отдельный выбор модели ревью Jira сохраняет глобальную модель.
- [ ] Для выбранного режима обязательные переменные окружения отмечены только как `present` / `missing`; внешние секреты пользователь задал вне чата, окружение процесса запуска обновлено.
- [ ] Только для MCP `required`: проверено наличие переменных окружения хоста и токена; проверка конечных точек и инструментов до создания каталога задачи не требуется.
- [ ] Только для Jira: локальный сервис настроен, `/health` успешен, расширение загружено и читает конфигурацию проекта. Локальный токен расширения передан пользователю; GitLab API настроен только при выборе поиска MR.
- [ ] Конфигурация префикса содержит параметры проекта, выбранные `ide` и `mcp_enabled`; для отдельной модели ревью Jira с OpenCode сохранён полный `provider/model` через `opencodeModel` (`opencode_model` в файле) и подтверждён `--model` в help CLI, пустое значение оставляет штатный выбор; при повторной настройке перезапись записи допустима.
- [ ] `review-tasks init` не запускался; каталог задачи не создавался.
- [ ] Пользователю передан следующий шаг: `review-init` с задачей/MR.
