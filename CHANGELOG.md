# История изменений

Все значимые изменения проекта документируются в этом файле.

## [1.1.1] - 2026-10-07

### Добавлено

- Замечания в Markdown-отчёте получили сквозные номера: теперь на конкретное замечание можно ссылаться по номеру.

### Изменено

- Проект получил название RDV AIR.
- В README подробнее описаны роли «аудитор → критик»: поиск кандидатов и проверка замечаний перед публикацией.
- Добавлено описание MCP и локальных знаний, которые агент использует при ревью.
- Показаны варианты оркестрации: один агент, разделение ролей и параллельные аудиторы.
- Описаны запуск из Jira и работа с Codex, Cursor и OpenCode.
- Добавлен блок «Вопрос-Ответ» по моделям, MCP, передаче кода, запуску ревью и работе с GitLab.

## [1.1.0] - 2026-10-01

### Добавлено

- В README добавлены таблицы поддерживаемых возможностей, схемы работы ревью, пример отчёта и FAQ по моделям, MCP, передаче кода и работе с GitLab.

## [1.0.1] - 2026-09-30

### Изменено

- В Stage 2 описание замечания теперь сначала показывает ошибочный результат, затем его причину. Рекомендация указывает конкретную правку; пример кода добавляется, когда он помогает понять исправление.
- В инструкциях ревью уточнена работа с UTF-8 и PowerShell. При повреждённом отображении русского текста агент повторно читает файл с правильной кодировкой перед анализом.

## [1.0.0] - 2026-09-25

### Добавлено

- Первый публичный релиз `review-tasks` для поэтапного ревью изменений 1С.
- Подготовка отдельного каталога ревью по ключу задачи GitLab или Merge Request. В проверку попадают изменённые модули BSL и тексты запросов в макетах отчётов СКД.
- Запуск Stage 1 и Stage 2 в Codex, Cursor и OpenCode с проверкой результата и созданием Markdown-отчёта.
- Skills `review-setup` и `review-init` для установки, настройки проекта и подготовки каталога задачи.
- Ручной запуск без Jira и внешних MCP-серверов; при необходимости можно подключить MCP для внешнего подтверждения замечаний.
- Запуск ревью со страницы Jira через расширение Chrome и локальный сервис, включая настройки проекта и отдельную инструкцию для задачи.
- Инструкции по установке, настройке Git и MCP, запуску ревью и диагностике ошибок.
