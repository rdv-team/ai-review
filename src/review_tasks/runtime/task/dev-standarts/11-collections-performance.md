# Производительность коллекций

### std452: Поиск в коллекциях значений
- **Ключи:** `Массив`, `Соответствие`, `Найти`, `Получить`, `Вставить`, `НайтиСтроки`, `СравнениеЗначений`, `Индексы.Добавить`, `Сортировать`
- **Критичность:** Важно
- **Инструкция:** Для быстрого поиска в больших таблицах значений должны быть созданы индексы. Предложить добавить индексы, если используется `НайтиСтроки` на большой таблице без индексации.
- **Инструкция (п. 3.1):** При многократной проверке наличия элемента в `Массив` через `Найти()` использовать `Соответствие`, если порядок элементов не важен. Поиск в массиве — O(n), по ключу соответствия — O(1) в среднем. Особенно важно при поиске внутри циклов и больших объёмах данных.
```bsl
// Плохо: линейный поиск
Обработанные = Новый Массив;
Если Обработанные.Найти(Номенклатура) = Неопределено Тогда
    Обработанные.Добавить(Номенклатура);
КонецЕсли;

// Хорошо: поиск по ключу
Обработанные = Новый Соответствие;
Если Обработанные.Получить(Номенклатура) = Неопределено Тогда
    Обработанные.Вставить(Номенклатура, Истина);
КонецЕсли;
```
